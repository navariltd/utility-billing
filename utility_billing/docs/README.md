# Utility Billing & Property Management — User Guide

This guide is written for the people who use the app: the front desk, the meter
reader, the billing clerk, finance and the property manager. Every guide is
task-oriented — what you are trying to do, which screen to open, which fields
matter, and what happens next.

New here? Start with [00 · Overview](./00-Overview.md), then set the app up
with [01 · Settings](./01-Settings.md).

## Conventions used in this guide

- **Bold** text is a field, button or menu item you will see on screen.
- `Monospace` text is a value, a file or a command you type.
- A block starting with **Good to know**, **Note** or **If something does not
  work** explains consequences, rules and the usual causes of a problem.
- Screenshots show the standard desk layout; your fields may be arranged by your
  administrator.
